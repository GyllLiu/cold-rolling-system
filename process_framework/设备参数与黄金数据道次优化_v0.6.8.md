# 冷二联设备参数与黄金数据道次优化说明（v0.6.8）

## 1. 本版结论

设备参数可以直接用于优化道次，但不能只凭设备尺寸唯一算出全部工艺参数。本版采用“工艺规则定边界、黄金数据提供真实厚度边、轧制力机理模型做设备校核”的组合方式：

1. 先确定能够满足首道、末道和逐道递减规则的最少道次数。
2. 从 1127 段黄金高速平台中反向拼接真实的“入口厚度 → F1出口厚度 → F2出口厚度”候选链。
3. 没有合适历史链时，使用末道优先的确定性规则生成候选路线。
4. 对每个候选道次同时计算 DAT 轧制力预测和物理轧制力校核值。
5. 任何机架的保守校核值超过 1000T 就淘汰；同等道次数和质量等级下，选择最大负荷较低、负荷及压下曲线较平顺的路线。

因此，本版不是把摩擦系数 0.08 直接代入一个公式就给出道次，也不是简单照抄某条历史记录。

## 2. 已采用的设备与工艺条件

| 项目 | 当前值 | 本版用途 |
|---|---:|---|
| 工作辊直径 | 380 mm | 计算接触弧长和辊系弹性压扁 |
| 支撑辊直径 | 1000 mm | 设备档案；待获得辊系挠度/板形模型后使用 |
| 辊身长度 | 1750 mm | 产品宽度硬边界 |
| 单机架最大总轧制力 | 1000 T | F1、F2各自的硬性安全门槛 |
| 正常摩擦系数 | 0.08 | 正常润滑物理模型的固定工程假设 |
| 正常轧制速度 | 400—1000 m/min | 定义正常高速润滑工况；当前不单独预测速度 |

注意：DAT 中没有可用的轧制油温度、流量、压力和黏度连续量，只有润滑系统状态信号。因此 μ=0.08 是车间提供的正常润滑基准，不是从 DAT 唯一拟合出的真实摩擦系数。摩擦和材料变形抗力在现有无牌号标签数据中无法完全分离。

## 3. 道次规划的硬约束

| 约束 | 当前规则 | 目的 |
|---|---|---|
| 首道当前上限 | F1≤53%，F2≤46% | 厂家已给出F1 52.4%、F2 45.6%的可行路线，按整百分点向上取整；后续仍可用正式工艺限值替换 |
| F1主变形 | 每道 F1 至少比 F2 高 0.5 个百分点 | 保证“F1做主变形、F2做精调” |
| 逐道递减 | 后一道的F1、F2及本道总压下率均至少下降0.5个百分点 | 避免中间或末道突然加重 |
| 常规末道优选 | F1 28%—35%，F2 25%—32% | 保护成品板形 |
| 常规末道复核 | F1最高38%，F2最高35% | 超过就增加道次或重新规划 |
| 约0.2 mm末道 | F2 20%—25% | 采用厂家薄规格经验边界 |
| 设备轧制力 | 每个机架保守校核值≤1000T | 防止只看压下率而忽略宽度、硬度和摩擦 |
| 宽度 | ≤1750 mm，同时不能超出当前模型训练范围 | 辊身硬边界和模型覆盖双校核 |

这些比例不是铝材的统一行业常数，而是当前工厂规则与临时边界。行业资料明确指出，道次优化是受轧制力、功率、转矩、张力、速度及压下率共同约束的负荷分配问题，不能只用一个固定压下率决定。

## 4. 轧制力计算方法

本版使用 Bland–Ford–Hill 思路的平均压力近似，并迭代加入 Hitchcock 工作辊压扁：

```text
Δh = h入口 - h出口
l = √(R' × Δh)
σ张力 = (后张应力 + 前张应力) / 2
qμ = [exp(μ × l / h平均) - 1] / (μ × l / h平均)
F = 宽度 × l × max(1, 1.15 × k有效 - σ张力) × qμ
```

其中：

- `R'` 是按轧制力迭代得到的压扁后工作辊半径；初始半径为190 mm。
- `k有效` 是材料在当前厚度、累计加工硬化和当前数据条件下的等效变形抗力。
- `μ` 当前固定为0.08。
- 宽度和接触弧长使用 mm、应力使用 MPa，最后换算为吨力 T。

### 为什么还要用黄金数据反算

同样的设备和压下量，1060、1100、3003及不同来料状态的变形抗力不同。现有 DAT 缺少可靠的逐卷牌号/状态标签，所以本版不假装知道每卷的真实材料曲线，而是：

1. 固定正常润滑 μ=0.08。
2. 用黄金平台中的实际厚度、宽度、前后张力和实际轧制力反算 `k有效`。
3. 按 F1/F2 和入口厚度区间分别统计 P05、中位数、P95。
4. 中位数用于候选路线排序；P95用于保守设备校核。

### 安全校核口径

每个机架的保守值取二者较大者：

```text
安全校核轧制力 = max(
  DAT直接模型预测 + DAT模型P95误差,
  物理模型按P95变形抗力计算值
)
```

这样不会因为某一个模型恰好算得偏低而放行。页面仍显示原 DAT 模型的推荐轧制力，同时增加“设备校核/1000T”；物理模型只用于筛选和风险校核，未替换原有展示模型。

这个精度说明物理模型适合作为设备可行性和候选路线排序工具，但还不适合作为精确的生产轧制力首设模型。主要缺口是逐卷牌号、来料状态、真实油温/黏度/流量、辊径磨损、材料力学性能及电机转矩/功率边界。

## 7. 与厂家路线的关系

- 6.4→0.77的新路线与厂家曲线保持接近，并满足F1、F2和本道总压下率逐道下降。
- 6.4→0.33仍基本复现厂家给出的首道重压、末道轻压路线。
- 厂家路线不是被写死在程序里，而是作为验收参考；当黄金数据存在更平顺、负荷更低且不违反工艺规则的路线时，系统允许小幅调整中间厚度。
- “F1主变形、F2微调”现已成为硬约束，不再只靠候选数据碰巧满足。

## 8. 当前仍不能解决的事项

1. 1000T目前按每个机架总轧制力理解；需要设备方最终确认报警值、持续允许值和传动/操作侧口径。
2. 缺少电机额定功率、转矩和电流限值，因此400—1000m/min暂时不能形成完整的功率/转矩安全门槛。
3. 支撑辊直径不能单独决定轧制力；要做辊系挠度和板形模型，还需要工作辊凸度、弯辊、辊径磨损、辊系弹性和板形测量口径。
4. μ=0.08只代表正常润滑。润滑异常时不能继续沿用；后续应增加油温、黏度、流量/压力及喷淋状态。
5. 黄金数据虽然经过稳定性清洗，但没有真实卷ID，跨道次链是不同日期真实边的组合，不代表同一卷历史复现。

## 9. 下一步最小验证

1. 请厂家只审核厚度路线、各机架压下率和道次数，优先覆盖7→0.7、7→0.4、7→0.3、6→0.5、6.4→0.77、6.4→0.33。
2. 让厂家标记“不允许”“可试”“常用”三档，并给出需修改的具体道次和机架。
3. 在现场试用记录中继续保存牌号、来料状态、目标状态、推荐路线和主操最终值，再按时间与DAT对齐。
4. 获得电机转矩/功率边界和润滑连续量后，再把当前轧制力单约束升级为轧制力+功率+转矩+润滑多约束。

## 10. 文献依据

1. Yang等的冷轧规程优化研究把轧制力、功率、转矩、速度、张力和压下率作为联合约束，并采用Bland–Ford–Hill公式计算轧制力：<https://doi.org/10.1155/2022/9167017>
2. Li与Lagergren对铝合金冷轧力模型的评估指出，流动应力、Hitchcock接触长度和摩擦系数都会显著影响轧制力；把钢的参数处理直接用于铝会出现较大偏差：<https://doi.org/10.1002/srin.200005714>
3. Zhang与Lenard的铝冷轧试验表明，压下量、轧速、润滑剂种类和黏度都会改变摩擦、前滑和轧制分离力：<https://doi.org/10.1016/0924-0136(92)90346-T>
